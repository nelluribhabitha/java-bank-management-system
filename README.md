# Java Bank Management System

A console-based Bank Management System developed using Java to practice Object-Oriented Programming concepts, interfaces, methods, conditional statements, and user input.

## Features

* SBI and KOTAK bank selection
* Deposit money
* Withdraw money
* Check account balance
* CIBIL-based loan eligibility
* Loan amount validation
* Interest calculation
* Monthly EMI calculation
* Multiple transactions

## Technologies Used

* Java
* VS Code
* GitHub

## Java Concepts Used

* Interfaces
* Object-Oriented Programming
* Classes and Objects
* Methods
* Conditional Statements
* Loops
* Scanner for user input
* Basic input validation

## How to Run

1. Install Java JDK.
2. Download or clone this repository.
3. Open the project folder in VS Code or another Java IDE.
4. Compile the program:

```bash
javac User.java
```

5. Run the program:

```bash
java User
```
